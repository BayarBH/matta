【対象ユーザー】ネットバンキングを使うすべての預金者と、その家族。電話で指示されながら自分で振込ボタンを押してしまう特殊詐欺の被害は、高齢者だけでなく20〜30代にも広がっています。

【課題】2025年の特殊詐欺被害は1,423.1億円。振込型のうち495.3億円がインターネットバンキング経由でした。窓口なら行員の「ひと声」で止まる振込も、アプリには止める人がいません。一律の限度額引き下げは正当な支払いまで止めてしまいます。

【ソリューション】マッタは、冷静なときに本人が署名したルール（ユリシーズ契約）で振込を見守るAIエージェントです。日常の支払いは即時に通り、範囲外の振込だけを保留または家族（見守り人）の承認待ちにします。保留中はGeminiのAIガーディアンが窓口の行員のように一つずつ質問し、詐欺の兆候があればコードがエスカレーションして見守り人に理由を届けます。

【特徴】①AIは止められるが、通せない：お金は銀行サービスの決定論的なルールでしか動かず、AI側からは保留を強める操作しかできません。②「保護をオフに」対策：ルールを緩める変更や見守り人の変更は72時間後か見守り人の同意でのみ有効。③受取人名やメモはツールを持たない読み取りAIがデータとして扱い、指示として実行しません。④両サービスの全ステップをブラックボックスに記録。Cloud Run 2サービス、Gemini、Firestore、Cloud Tasks、Firebase Authで構成し、held-out評価の結果も公開しています。
